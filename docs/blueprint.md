# **App Name**: Learnify Studio

## Core Features:

- Course Catalog: Browse course catalog with categories, search, and learning paths.
- Course Detail: View detailed course landing page with syllabus, promo video, instructor profile.
- Shopping Cart & Checkout: Add courses to cart and proceed to Izipay payment gateway.
- Content Access: Unlimited access to purchased course content, including recorded videos and live sessions.
- Progress Tracking: Automatically track user progress within each course and video.
- Community features: Users can add courses to a wishlist, leave comments, and generate certificates.
- AI resource suggestion: AI-powered tool that will recommend learning resources based on what the user likes to review.

## Style Guidelines:

- Primary color: Deep navy blue (#003459) to evoke trust and stability, aligning with e-learning objectives.
- Background color: Light desaturated blue (#E0F2F7), offering a clean and unobtrusive backdrop.
- Accent color: Soft yellow-orange (#F79256) to draw attention to key CTAs.
- Body and headline font: 'Inter', a modern sans-serif for a clean and objective user experience.
- Code font: 'Source Code Pro' for code snippets.
- Responsive design to ensure optimal UX across devices.
- Subtle transitions and animations for a smooth user experience.
